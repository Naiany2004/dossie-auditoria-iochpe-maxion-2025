## 4. Base de dados sintética

A base sintética foi desenvolvida exclusivamente para fins didáticos. Seus registros individuais não correspondem ao cadastro real de ativos da companhia.

Os valores agregados foram utilizados como referências para demonstrar a conciliação da base e a execução de verificações automatizadas. As premissas de geração, os critérios adotados e as limitações dos dados devem ser consultados nos códigos e papéis de trabalho correspondentes.

Portanto, os resultados obtidos com a base sintética não constituem evidência direta sobre os registros individuais reais da Iochpe-Maxion S.A.

## 5. Procedimentos e limitações

Os papéis de trabalho identificam os procedimentos executados com base em informações públicas, os procedimentos planejados que dependem de acesso a informações não disponíveis e as simulações realizadas para fins acadêmicos.

Procedimentos como confirmações externas, inspeções físicas e acesso a sistemas internos não devem ser interpretados como executados quando não houver evidência de sua realização.

Os resultados e as conclusões devem ser interpretados considerando as fontes consultadas, as limitações de acesso e a natureza acadêmica do trabalho.
